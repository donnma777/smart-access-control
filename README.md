# 🔒 Smart Access Control

**高度なアクセス制御プラグイン**

このWordPressプラグインは、クローラー・User-Agent・IPアドレスを組み合わせて、投稿や固定ページごとにアクセスを精密に制御する管理者向けツールです。
検索エンジン、AIクローラー、スクレイピングツール、不正なブラウザアクセスを柔軟に許可・拒否できます。

## 🌟 主な機能

### 1. グローバル設定とページ個別設定
*   **グローバル設定が最優先**で、投稿・固定ページの個別設定より先に適用されます。
*   User-Agent / IPアドレスを **ページ** と **メディア** で別々に制御可能です。
*   選択肢: 「適用しない / 新規投稿で適用 / 全ページでブラックリスト / 全ページでホワイトリスト」

### 2. モードの挙動（ページ・メディア共通）
| モード | 解説 | ページ | メディア |
| --- | --- | --- | --- |
| ブラックリスト | 一致したものを拒否 | 選択したものを拒否 | 選択したものを代替テキストに置換 |
| ホワイトリスト | 一致したものだけ許可 | 選択したものだけ許可 | 選択したものだけメディア表示 |
| 全許可 | すべて許可 | 制御なし | メディア表示 |
| 全拒否 | すべて拒否 | アクセス拒否 | すべて代替テキストに置換 |

### 3. メディアの代替テキスト機能
クローラーやボットに対して、メディアを代替テキストに置き換えて表示できます。
*   **固定テキスト（設定画面）**: ブラック/ホワイトリスト時の代替テキスト（空欄なら置換しません）
*   **アイキャッチメディアの固定テキスト**: 専用テキストを優先使用（未入力なら通常の代替テキスト）
*   **ブロック単位の代替テキスト**: Gutenbergのメディアブロック（core/image, core/gallery, core/cover）ごとに指定
*   **プレビュー機能**: 「代替テキスト置換プレビュー」で結果を確認可能

### 4. 定義リストと自動更新
*   **User-Agent 定義1 & 2**: 既知ボットと不正UAパターン（部分一致）を管理
*   **IPアドレス範囲 1 & 2**: CIDR形式の範囲指定。公開IPリストURLの **自動更新** に対応

### 5. 診断ツール & 使い方ガイド
*   **診断ツール**: 自分のIP/UAの確認、IP判定テスト
*   **アプリの使い方**: 管理画面内に詳細マニュアルを内蔵

## ⚠️ 重要な注意事項と免責事項

### 1. 制御の優先順位と技術的制限
本プラグインは **WordPress (PHP) レイヤー** で動作します。そのため、以下の制限があります。

*   **robots.txt やサーバー設定が優先されます**:
    `robots.txt`、Webサーバー設定（Apache/Nginx）、WAF、CDNなどで拒否されているアクセスは、本プラグインに到達する前にブロックされます。本プラグインで「許可」しても、上位レイヤーで拒否されていればアクセスできません。
*   **PHPが実行されないアクセスは制御できません**:
    画像ファイル、CSS、JSなどの静的ファイルへの直接アクセスや、キャッシュプラグイン（WP Super Cacheなど）によって生成された静的HTMLへのアクセスは、PHPを経由しないため制御できません。
    *   **対策**: 会員限定ページなど重要なページでは、キャッシュプラグインの除外設定を行ってください。

### 2. 完全なブロックの保証はありません
このプラグインは User-Agent 文字列や IPアドレスに基づいて判定を行いますが、これらは偽装可能です。
*   **UA偽装**: 悪意のあるクローラーが一般的なブラウザの User-Agent を偽装した場合、UA判定だけでは防げないことがあります（IP制限との併用を推奨）。
*   **保証の限界**: 本プラグインは、アクセス制御の労力を減らし、既知のボットを効率的に管理するためのツールです。完全なセキュリティ防御が必要な場合は、WAFなどの導入をご検討ください。

### 3. 設定時の注意
*   **自分自身をブロックしない**: 特に「IPアドレス評価」でホワイトリスト（許可）モードを使用する場合、自分のIPアドレスを含めないとページを閲覧できなくなります（管理画面には影響しません）。

## 🚀 インストールと設定

### 基本設定
1.  プラグインを有効化します。
2.  **設定 > アクセス制御** に移動します。
3.  **「アプリの使い方」タブ** を開き、手順に従って初期設定（リスト作成）を行います。
4.  **一般設定**でグローバル設定を決めます（ここでの選択が最優先）。
5.  各投稿・固定ページの編集画面で個別設定を行います（グローバルが「新規投稿で適用」の時のみ有効）。

### 代替テキスト機能の使い方
1.  **設定 > アクセス制御** の「代替テキスト」欄に固定テキストを入力します（空欄なら置換しません）。
2.  投稿編集画面で：
    *   メディアブロックを選択 → 右サイドバーの「代替テキスト（クローラー用）」に入力
    *   アイキャッチ画像セクションの専用テキストを入力（必要な場合）
3.  保存後、「代替テキスト置換プレビュー」で結果を確認できます。
4.  設定した評価条件に該当するアクセスには、メディアの代わりに代替テキストが表示されます。
